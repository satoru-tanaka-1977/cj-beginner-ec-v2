# Apparel Brand Product Page（アパレルブランド 商品ページ） [2周目]

CODEJUMP 初級編「アパレルブランド（商品ページ）」課題の2周目の制作リポジトリです。

## 概要

アパレルブランドのECサイトにおける商品単体ページのコーディングを行っています。全体のレイアウト設計、数量・サイズ表のテーブル装飾、スマホ表示時のグローバルナビゲーションの横スクロール対応などを実装します。

## コーディング仕様

- **使用フォント**: 
  Google Fonts「`Raleway`」
- **コンテンツ幅**: 
  - 全体最大幅: 1000px
  - コンテンツ最大幅: 800px
- **表組み**: 
  数量とサイズの表に `table` タグを使用
- **レスポンシブ**: 
  - ブレークポイント: 896px
  - スマホ時: グローバルナビゲーションを横スクロール可能にする

## 使用技術

- HTML5
- CSS3
- Google Fonts (Raleway)
- Git / GitHub
